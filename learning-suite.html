How the apps connect

One result updates everything else

Every app uses the same building block: the learning outcome. When results come in, the other apps update, with no copying between systems.

Shared by all apps: learning outcomes
  1. STEP 1 · ON-SCREEN EVALUATIONAnswer sheets are marked and results publishedEvery mark is tied to a learning outcome.
  2. STEP 2 · IMPROVEMENT PLANSEach learner's plan updates by itselfWeakest outcomes get goals, practice and a mentor.
  3. STEP 3 · PEER LEARNINGStudy groups are re-formedStrong and developing learners are paired on the same outcome.
  4. STEP 4 · PEDAGOGY ENGINETeachers see which outcomes need a new lessonLessons are redesigned before the next exam.

The loop repeats every term. Each app also works fully on its own, so you can start with one and add the others later.
